# M6 — Command palette and launcher demo

```sh
make run
```

1. **Run any action.** `Cmd/Ctrl+Shift+P`, type `new tab`, `Enter`: a tab opens. Try
   `font`, `scroll`, `reload`: every action from the reference is there with its keybinding chip.
2. **Workspaces.** Create `infra` (`Cmd+Alt+W`, *Create workspace…*), then open the palette and
   type `@infra` or `@def`: `Enter` jumps to that workspace.
3. **Tabs.** Open a few tabs, palette, type `#`: *Go to tab: …* rows list them; `Enter`
   activates the selected one.
4. **Themes.** Palette, type `~tokyo`: the UI recolours as you type and as you move the
   selection. `Esc` restores the old theme; `Enter` keeps Tokyo Night.
5. **Recency.** Run *Rename tab*, reopen the palette and type `ren`: it is now first. Quit and
   restart: `~/.local/state/microterm/mru.json` keeps the order.
6. **Launcher.** `Cmd/Ctrl+Shift+L` (or right-click `+`). Add to the config while it is open:

   ```toml
   [[launch]]
   name = "htop"
   command = ["htop"]
   ```

   Save: *htop* appears in the launcher immediately. `Enter` opens it in a new tab,
   `Cmd/Ctrl+Enter` in a new window.
7. **Docs.** `make docs` regenerates `site/src/content/docs/docs/reference/actions.md`;
   `make docs-check` fails if it is stale.
