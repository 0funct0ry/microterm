# M10.4 — ctl: agent integration demo

```sh
make run
```

Run the commands below in a **second terminal** (outside microterm) unless a step says otherwise.

1. **Install the skill.**
   ```sh
   microterm ctl skill install --agent claude --scope project --print   # shows the path
   microterm ctl skill install --agent claude --scope project
   microterm ctl skill install --agent claude --scope project           # prints "unchanged"
   ```
   `.claude/skills/microterm-ctl/SKILL.md` exists and lists the patterns, exit codes, selectors and
   the trust-model warning. `microterm ctl skill uninstall --agent claude --scope project` removes
   the directory again. With `--agent generic`, an existing `AGENTS.md` keeps its content and gains
   one managed block.
2. **Register the MCP server** (optional, instead of or next to the skill).
   ```sh
   claude mcp add microterm -- microterm ctl mcp
   ```
3. **Drive microterm from Claude Code.** Start `claude` in the project and ask:
   > Run the tests in a new microterm tab, then start the dev server in another tab and tell me
   > when it is ready. If you need my approval for anything, ask me through microterm.

   Expected, visible in the running window:
   - a tab appears and runs the tests (`microterm ctl pane run --json -- cargo test`); Claude
     reports the exit code and the failing lines from the returned output;
   - a tab titled `dev` starts the server (`pane run --detach --title dev -- npm run dev`) and
     Claude waits with `pane wait --match title:dev --match 'ready on' --timeout 120s`, then reads
     errors with `pane get-text --match title:dev`;
   - when Claude needs a decision it runs `pane status set --state waiting "approve migration?"`
     (amber dot on its tab) and `pane notify --level attention …` (badge, toast, and an OS
     notification while microterm is unfocused).
4. **Check the MCP server by hand.**
   ```sh
   printf '%s\n' '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' | microterm ctl mcp | head -c 400
   ```
5. **Clean up.** `microterm ctl tab close --match 'title:dev' --force`.
