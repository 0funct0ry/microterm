# M11.5 — Snippets demo

```sh
make run
```

1. **Off by default.** Press `⌘⇧S` (`Ctrl+Shift+S` on Linux): only a "Snippets are disabled"
   toast with an **Open config** button appears. `⌘⇧P` then `!` shows no snippet provider, and in
   another terminal `microterm ctl snippet list` exits `10` (`echo $?`).
2. **Turn it on.** Add to `microterm.toml` (no restart):
   ```toml
   [snippets]
   enabled = true
   ```
   `⌘⇧S` opens the panel on the right with the cursor in the search field. Click **+**, enter the
   title `Print uuid` and the body `echo {{uuid}}`, press `⌘S`. Click the row: the **literal**
   text `echo {{uuid}}` appears at the shell prompt (templates are still off). Clear the line
   (`Ctrl+U`).
3. **Templates.** Set `templates = true`. Click the row: `echo ` plus a fresh uuid is typed and
   not run. Double-click it: it is inserted once, not twice.
4. **Fill dialog.** Add this snippet (the panel's **+**, or paste it into `snippets.toml`):
   ```toml
   [[snippets]]
   title = "New branch"
   body = '''cd {{ git_root default="." }} && git checkout -b {{ b := input "Branch" | kebab }} && git push -u origin {{ $b }}'''
   ```
   `⌥`-click it: the fill dialog opens with a **Branch** field. Type `Fix The Bug`; the preview
   shows `… git checkout -b fix-the-bug && git push -u origin fix-the-bug`. `Enter` types exactly
   that text; `⌥Enter` types it and runs it; `Esc` cancels and sends nothing.
5. **Cursor.** Add `body = "psql postgres://{{ user }}@localhost/{{ input \"Database\" default=\"dev\" }}{{ cursor }} -c 'select 1'"`
   as another snippet, insert it and press `Left`/type: the shell cursor sits at the marker.
6. **Live file.** In an editor change a title in `snippets.toml`: the panel updates at once. Break
   the file (`[[snippets]`): a banner names `snippets.toml:LINE:COL` and the old list stays. Fix it:
   the banner goes. Edit a snippet in the panel and save: the comments and other entries in the
   file are byte-identical (`diff snippets.toml.bak snippets.toml` shows only your change).
7. **ctl and MCP.** With a snippet `k8s-logs` whose body is
   `kubectl -n {{ choice "Namespace" "dev" "prod" }} logs -f {{ input "Pod" }}`:
   ```sh
   microterm ctl snippet insert k8s-logs --pane $MICROTERM_PANE --var Namespace=dev --var Pod=api --run
   microterm ctl snippet insert k8s-logs --pane $MICROTERM_PANE   # exit 11, lists "Pod (input)" and "Namespace (choice)"
   microterm ctl mcp   # tools/list now contains microterm_snippet_list, _expand and _insert
   ```
8. **Palette and keys.** `⌘⇧P`, type `!`, pick a snippet and press `Enter` (insert) or `⌥Enter`
   (run). Give a snippet `keys = "cmd+alt+1"` and press it.
9. **Gates again.** Set `enabled = false`: the panel closes, `!` and the keys go away, and
   `ctl snippet list` exits `10` again.
