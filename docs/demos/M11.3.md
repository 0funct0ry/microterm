# M11.3 — Tab colors demo

```sh
make run
```

1. **Menu.** Open two tabs. Right-click one: below **Rename…** the **Tab Color** heading shows a
   2 × 5 grid (ring, blue, purple, pink, red / orange, yellow, green, teal, gray). Click pink: the
   tab gets a pink top bar and tint. Right-click again: the check is on pink. Click the ring: the
   color is gone.
2. **Keyboard.** Right-click, press `↓` until the grid, `→` twice, `Enter`: the tab turns purple.
3. **Palette.** `⌘⇧P`, run **Tab: Set color…**, type `teal`, `Enter`; **Tab: Clear color** removes it.
4. **ctl.**
   ```sh
   microterm ctl events --type tab.color_changed --json &
   microterm ctl tab color --match 'title:*build*' orange
   microterm ctl tab list --json
   ```
   The matching tab turns orange and the event prints `{"tab":…,"color":"orange","source":"manual"}`.
5. **Rules and domains.** Add to `microterm.toml` (hot reloaded):
   ```toml
   [[tab_bar.color_rules]]
   match = "domain:prod-*"
   color = "red"

   [[ssh_domains]]
   name = "prod-db"
   host = "db.example.com"
   ```
   Every tab opened in `prod-db` is red. Color one pink by hand: it overrides; the ring then
   restores the red. Hover the tab: `Color: red (rule: domain:prod-*)`.
6. **Remote persistence.** Color a 3-pane SSH tab teal, then `microterm ctl` the connection down
   and back (or sleep the laptop): the color is still teal and a second attached client sees it.
7. **Styles and themes.** Set `[tab_bar] color_style = "dot"` then `"none"`; switch theme with the
   palette (`~`): colors re-resolve live with no restart.
