# M12 — Serial ports demo

No hardware is needed on Linux: a `socat` pty pair stands in for a device. (On macOS the
`serialport` crate cannot open a pty; use a real USB serial adapter or an Arduino.)

```sh
make run
```

1. **List.** In another terminal: `microterm serial --list` prints each port with
   `VID:PID` and product name.
2. **Virtual pair (Linux).**
   ```sh
   socat -d -d pty,raw,echo=0,link=/tmp/ttyA pty,raw,echo=0,link=/tmp/ttyB
   ```
   `microterm serial /tmp/ttyA --baud 9600` opens a tab titled `ttyA @ 9600`. In a third
   terminal `echo hello > /tmp/ttyB` prints `hello` in the tab; `cat /tmp/ttyB` then typing in
   the tab shows your text there.
3. **Launcher.** `⌘⇧L` → **Connect to serial port…** lists discovered ports; **Other port…**
   takes `/tmp/ttyA 9600`. Add a `[[serial_ports]]` entry and it shows as **New tab in NAME**.
4. **Line endings.** `microterm serial /tmp/ttyA --line-ending crlf` and run
   `xxd < /tmp/ttyB`: Enter arrives as `0d 0a`. With `--local-echo` your typing is drawn
   in the tab too.
5. **Unplug and replug.** Stop `socat` (Ctrl-C): the tab dims and a card says "Serial port ttyA
   disconnected" with a countdown and an attempt number; typing does nothing. Start `socat` again
   with the same links: within a few seconds the card disappears, the screen is intact and
   "[serial port reconnected]" is printed. **Retry now** skips the wait; **Close tab** closes
   the port.
6. **DTR / break.** Palette → "Serial: toggle DTR" twice on an Arduino resets the board (its
   boot banner appears). "Serial: send break" sends a 250 ms break. A toast reports line state.
7. **Errors.** `microterm serial /dev/null --parity mark` exits 1 with "invalid parity".
   A port you may not open (permission denied) shows "Could not open …" with **Retry**.
