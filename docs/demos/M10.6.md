# M10.6 — VT conformance demo

```sh
make run
```

Run these in a tab of the running window, then again in an SSH-domain tab (they behave the same).

1. **Colour queries read the program's overrides.**
   ```sh
   printf '\e]4;1;?\e\\'            # the reply `rgb:RRRR/GGGG/BBBB` is typed back at the prompt
   printf '\e]4;1;rgb:ff/00/00\e\\\e]4;1;?\e\\'
   ```
   The second reply is `rgb:ffff/0000/0000`. Set `terminal.osc_color_report = "8-bit"` in the
   config: the next query answers `rgb:ff/00/00`; `"none"` sends nothing.
2. **Special colours.**
   ```sh
   printf '\e]5;0;rgb:ff/00/00\e\\'; printf '\e[1mbold text\e[0m\n'
   printf '\e]105\e\\'
   ```
   Bold text is red until `OSC 105` resets it. `OSC 5;1` does the same for underlines.
3. **Progress on the tab.**
   ```sh
   printf '\e]9;4;1;40\e\\'     # the tab shows a 40 % progress line and tooltip
   printf '\e]9;4;0\e\\'        # clears it
   microterm ctl pane list --json | head -20   # `status` shows the progress while it is live
   ```
   Run `microterm ctl pane status set --state waiting "approve?"` first and repeat the progress
   line: the tab keeps showing `waiting`.
4. **Notification.**
   ```sh
   printf '\e]9;build done\e\\'
   ```
   Switch to another tab first: the tab gets a badge, a toast appears and, with the window
   unfocused, an OS notification. `microterm ctl events --type pane.notification --json` shows
   `"source": "osc9"`. With `terminal.osc_notifications = false` nothing happens.
5. **Pointer shape.**
   ```sh
   printf '\e]22;pointer\e\\'   # the pointer over the pane is a pointing hand
   printf '\e]22;\e\\'          # back to the I-beam
   ```
6. **XTSHIFTESCAPE.** In a program with mouse tracking (htop), Shift-drag selects text. After
   `printf '\e[>1s'` Shift-modified clicks reach the program instead; `printf '\e[>0s'`
   restores the bypass.
7. **DECSLRM is unsupported.**
   ```sh
   printf '\e[?69$p'    # reply `ESC [ ? 69 ; 0 $ y`: mode 69 is not recognised
   ```
   See `docs/adr/0002-decslrm-margins.md`.
8. **The support page.** Open `site/src/content/docs/docs/reference/terminal-api.md` (or run
   `make site-dev`) for the full table, and run `cargo test -p mt_term vt_conformance`.
