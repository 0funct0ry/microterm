# M12.5 — Animated GIF export demo

Needs `recording.enabled = true`.

```sh
make run
```

1. **Record.** `⌘⌥R`, run `ls --color`, `cargo build` in a project, open `vim`, type a line, quit
   with `:q!`, wait about 30 s without typing, run `echo done`, then `⌘⌥R` again.
2. **Export from the panel.** `⌘⇧Y`, select the recording, `⌘E`. `gif` is in the format list with
   its options in two panes (*Appearance* and *Text and timing*) that fit without scrolling. The
   output file is empty: click the **home** icon (it fills `~/<name>.gif`) or **browse**. Window
   chrome is `macOS`. Click the theme control to pick from the list, pick a margin colour from the
   swatches or type `#rrggbb`. Export to `~/demo-panel.gif`; the footer shows progress.
3. **Export from ctl.** With the same defaults:
   `microterm ctl recording export ID --format gif -o ~/demo-ctl.gif`, then
   `cmp ~/demo-panel.gif ~/demo-ctl.gif` prints nothing (identical bytes).
4. **Look at it.** Open the GIF in a browser: theme colours, bold text, the cursor, `vim`'s screen
   and the return to the shell, and the rounded title bar. The 30 s pause plays as 2 s
   (`idle_limit`).
5. **Smaller.** `microterm ctl recording export ID --format gif -o ~/small.gif --opt fps=5 --opt scale=0.5`;
   `ls -l ~/demo-ctl.gif ~/small.gif` shows a much smaller file.
6. **Options.** `--opt chrome=macos` adds traffic lights, `--opt theme="One Light"` re-themes it,
   `--opt theme=nope` exits 12 with "no theme named".
7. **Emoji and fallback.** Record `echo 日本 🙂 📦 🦀` and export: the emoji are drawn in colour
   (Noto style) and 日本 are `□` boxes; `--json` shows `fallback_cells: 2` and a warning.
   A recording started with a prompt on screen shows that prompt in its first frame.
8. **Cancel.** Export a long recording from the dialog and press the cancel button in the progress line at the bottom of the panel:
   neither the GIF nor a `.partial` file is left behind.
9. **Too big.** `--opt max_size_mb=1` on a long, busy recording stops with a hint to lower `fps` or
   `scale`, and writes nothing.
10. **Bench.** `make bench` prints `gif_bench: 60 s 80x24 @10 fps: … s, … MB` and records it in
    `bench/results/`.
