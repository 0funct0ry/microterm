# M12.4 — Recordings panel and export dialog demo

Needs `recording.enabled = true` (and `capture_input = true` for the VHS steps).

```sh
make run
```

1. **Record.** `⌘⌥R`, type `echo hello` + Enter and a couple more commands, `⌘⌥R` again. The
   "Saved …" toast shows **Open panel** and **Export…**.
2. **Panel.** Click **Open panel** (or press `⌘⇧Y` / `Ctrl+Shift+Y`). The new recording is listed
   under *Today* with its duration, size, grid size and an `input` badge. Press `⌘⇧Y` again to
   move focus away and once more to close it.
3. **Search.** Open the panel and type part of the title: the list becomes a ranked flat list.
   `Esc` clears it, `Esc` again hands focus back to the terminal.
4. **Replay.** Select the row and press `Enter` (or double-click): a new tab replays it.
   Right-click ▸ *Replay at 2×* plays it twice as fast.
5. **Rename.** `F2`, type a new title, `Enter`. `microterm ctl recording list` shows it, and the
   first line of the `.cast` file has it as `"title"`.
6. **Running row.** Start another recording with `⌘⌥R`: the panel shows it under *Recording now*
   with a pulsing dot and only a **Stop** button.
7. **Export.** Select a finished recording and press `⌘E` / `Ctrl+E`. Export it as `cast` (leave
   the defaults) and then as `vhs`; the output path follows the format. Both finish with a toast
   (**Reveal**, **Open**). For a recording made without input `vhs` is greyed out with "Needs
   input".
8. **Overwrite.** Export to the same path again: the first `Enter` warns, the second replaces.
9. **One panel at a time.** With snippets enabled, `⌘⇧S` closes the recordings panel and `⌘⇧Y`
   closes the snippets panel; each reopens at its own width.
10. **Delete.** Select a recording, press `Delete`, then `Esc` (nothing happens) and `Delete`,
    `Enter` (the file is gone). With `recording.confirm_delete = false` it goes at once.
11. **Gate.** Set `recording.enabled = false`: the panel closes, and `⌘⇧Y` only shows the
    "Recording is disabled" toast.
