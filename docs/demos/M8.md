# M8 — Quick select, copy mode and search demo

```sh
make run
```

1. **Quick select SHAs.** In a git repository run `git log --oneline -n 8`. Press
   **Cmd+Shift+Space** (Linux: **Ctrl+Shift+Space**). Every SHA gets a chip. Type one chip's
   letter: a `Copied <sha>` toast appears and the clipboard holds it. Paste to check.
2. **Quick select and paste.** Repeat, but type the label in **uppercase**: the SHA is copied
   and typed at the prompt.
3. **IPs.** Run `printf 'web-1 10.0.12.4:8080 Running\nweb-2 10.0.12.5:8080 Running\n'`
   (a stand-in for `kubectl get pods -o wide`). Quick select labels both addresses with their
   ports. Press `Esc` to cancel.
4. **Other patterns.** `echo https://example.com ~/src/api/main.rs 5f0c1a2b-3c4d-4e5f-8a9b-0c1d2e3f4a5b dev@example.com '#74ade8' 48213`
   labels all six. Add `disable_builtin = ["number"]` under `[quick_select]` and save: the
   number is no longer labelled the next time you open quick select.
5. **Copy mode.** Run `seq 1 300`, then **Cmd+Shift+X** (Linux: **Ctrl+Shift+X**). Press
   `g g` to jump to the top of scrollback, `j j`, then **Ctrl-v**, `j j j l` to select a block.
   The pill reads `V-BLOCK`. Press `y`: the block is copied and copy mode closes. Keys typed in
   copy mode never reach the shell.
6. **Motions and counts.** In copy mode try `5j`, `w`, `b`, `$`, `0`, `}`, `H` `M` `L`,
   `Ctrl-u` / `Ctrl-d`, and `G`. `v` then `Esc` clears the selection; `Esc` again exits.
7. **Search in copy mode.** Press `/`, type `150`, `Enter`: the cursor jumps there. `n` / `N`
   step. With `v` active the selection follows.
8. **Prompts.** With a shell that emits OSC 133 marks (or
   `printf '\e]133;A\a'` in your prompt), `[` and `]` jump between prompts.
9. **Search.** Run `seq 1 500`, press **Cmd+F** (Linux: **Ctrl+Shift+F**), type `250`. The view
   scrolls to the match and the bar reads `1 of 1`. Type `1` instead: many matches, step with
   `Enter` / `Shift+Enter`. Toggle case with `Alt+C` and regex with `Alt+R` (`^2\d\d$`).
10. **Remap.** Add to the config and reopen copy mode:

    ```toml
    [[copy_mode.keys]]
    key    = "ctrl+j"
    action = "PageDown"
    ```
