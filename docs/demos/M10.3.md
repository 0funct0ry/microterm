# M10.3 — ctl: notify, status and events demo

```sh
make run
```

Open two tabs. Run the following in a **second terminal** (outside microterm) unless a step says
otherwise. Find ids with `microterm ctl pane list`; below `$P` is the pane of the **background**
tab.

1. **Status dot, progress line and tooltip.**
   ```sh
   microterm ctl pane status set --pane $P --state working --progress 40 'running tests'
   ```
   The background tab shows an accent dot and a thin accent line two fifths of the way along its
   bottom edge. Hover the tab: the tooltip reads `working 40%: running tests`. `#` in the command
   palette lists the tab with the same text and dot.
2. **Every state.** Repeat with `--state waiting` (amber dot), `done` (green), `error` (red) and
   `idle` (no dot). `microterm ctl pane list --match 'status:waiting'` finds the pane;
   `microterm ctl pane status get --pane $P --json` prints the object.
3. **A TTL expires on its own.**
   ```sh
   microterm ctl pane status set --pane $P --state waiting --ttl 30s 'approve the deploy?'
   ```
   The amber dot disappears after 30 seconds without any further command.
4. **Inside a pane**, run `microterm ctl pane status set --state working building` and then
   `exit`: closing the shell removes the tab and its status. (Statuses also clear when a pane's
   process exits but its tab stays, as with `pane run --keep`.)
5. **Notify.**
   ```sh
   microterm ctl pane notify --pane $P --level attention 'tests done'
   ```
   A warning-coloured badge appears on the background tab and a toast shows. Click the tab: the
   badge clears. With another application in front of microterm, repeat the command: an OS
   notification appears too (on macOS from an unbundled build it may not; use `make bundle`).
   `--desktop` forces the OS notification even while microterm is focused.
6. **Rate limit.**
   ```sh
   for i in 1 2 3 4 5 6 7 8; do microterm ctl pane notify --pane $P "n$i"; done
   ```
   prints `microterm: N notification(s) dropped (rate limit)` for those beyond five in a second.
7. **Events.**
   ```sh
   microterm ctl events --type pane.command_finished,pane.notification,pane.status_changed
   ```
   In the other terminal repeat steps 1 and 5, and run a command in a shell with
   [shell integration](../../site/src/content/docs/docs/shell-integration.md): each shows up as a
   JSON line such as `{"type":"pane.status_changed","pane":12,"ts":"…"}`. `--match 'title:build*'`
   narrows to matching tabs; `--snapshot` prints the tree first. Quit microterm: `events` exits `2`.
8. **Config.** In `microterm.toml` set `[notifications]` `toast = "never"` and `badge = false`;
   save. The next `pane notify` shows neither, without a restart.
9. **Headless (tests).**
   ```sh
   cargo test -p mt_mux -p mt_proto -p mt_config
   cargo test -p microterm --features runtime-shaders --test ipc_e2e
   cargo test -p mt_ui --features runtime-shaders
   ```
