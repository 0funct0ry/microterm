# M12.73 — Pane badge and gutter marks demo

```sh
make run
```

Set `[private_osc]` / `enabled = true` in `microterm.toml` first. The steps are scripted in
`scripts/private_osc/` (`badge` and `marks`, also run by `all`).

1. **Badge.** `printf '\e]7718;badge;set;%s;error\a' "$(printf PROD | base64)"` shows a pill with a red dot and
   `PROD` in the bottom-right. Click and drag through it: selection and clicks work as usual.
2. **Not text.** Select all and copy, or run `microterm ctl pane get-text`: `PROD` is not there.
   Export a GIF of the pane: no badge. Narrow the pane below 24 columns: the badge hides. Run
   `vim`: it stays on the alternate screen.
3. **Menu.** Right-click the pane: the menu ends with `Badge "PROD" set by a program`.
4. **Clear.** `printf '\e]7718;badge;clear\a'`, closing the pane or `reset` removes it.
5. **Marks.** Run `scripts/private_osc/marks`: three rows get a colored edge mark and a scrollbar
   tick. From the palette run *Next marker* / *Previous marker*: they jump between them, and the
   Markers section lists them as `program (7722)`.
6. **Together with triggers.** Add a trigger rule with a `marker` action: both kinds share one
   list. Turn `triggers.enabled` off: the program marks still work.
7. **Resize.** Resize the window and scroll: each mark stays on its row. `ClearMarkers` removes
   both kinds.
8. **Recording.** While recording the pane, a new mark adds a marker to the recording.
9. **Master switch / gates.** Toggle private OSC (or set `badge = false` / `mark = false`): the
   badge and marks vanish and do not return.
10. **Over SSH.** In an SSH pane run steps 1 and 5, drop and restore the connection: both are
    restored by the daemon replay.
