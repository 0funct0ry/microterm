# M5 — Tabs and workspaces demo

```sh
make run
```

1. **Real tabs.** `Cmd/Ctrl+T` opens a new tab running your shell (not a mock). `Cmd+1`/`Alt+1`
   jumps to tab 1; `Cmd+Shift+]`/`Ctrl+Tab` cycles.
2. **Directory inheritance.** `cd /tmp`, open a new tab, run `pwd`: it prints `/tmp`. Set
   `new_tab_cwd = "home"` in the config and repeat.
3. **Titles and the dot.** `sleep 100` in a tab: a dot appears on the tab and the title becomes
   `sleep` (or whatever the program sets). Set `[tab_bar] title_format = "{index}: {title}"`.
4. **Confirm close.** With `sleep 100` running press `Cmd/Ctrl+W`: a confirmation dialog names
   the process. `Esc` keeps the tab, `Enter` closes it. Try `confirm_close = "never"` too.
5. **Rename and reorder.** Right-click a tab, *Rename…*, type `api`, `Enter`. Drag tabs left and
   right to reorder. Middle-click closes a tab.
6. **Windows.** `Cmd/Ctrl+N` opens a second window in the same workspace. Run the palette action
   *Close window* to close one.
7. **Workspaces.** Click the workspace chip (or `Cmd+Alt+W` / `Ctrl+Alt+W`), choose *Create
   workspace…*, type `api`, `Enter`. The old windows disappear (their shells keep running) and
   a fresh window opens. Create `infra` the same way, add tabs and a second window to each.
8. **Switching.** Switch between `default`, `api` and `infra` from the chip, the switcher and
   `Cmd+Alt+]` / `Cmd+Alt+[`. Each workspace returns with its windows, tabs and running programs.
9. **Declared workspaces.** Add to the config:

   ```toml
   [[workspaces]]
   name = "api"
   tabs = [{ title = "server" }, { title = "logs", cwd = "/tmp" }]
   ```

   Quit, then `microterm --workspace api`: it starts with the two declared tabs.
10. **One instance.** With microterm running, run `microterm --workspace infra --cwd /tmp` in
    another terminal: a new window opens in the running app (switching to `infra`) and the
    command exits. `microterm --new-instance` starts a separate process.
11. **Window size.** Resize a window, quit, start again: the new window opens at that size
    (`window.remember_size`).
