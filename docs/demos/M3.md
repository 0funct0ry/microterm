# M3 — Configuration, hot reload and themes demo

```sh
make run
```

Keep the app open and edit the config in another window (`microterm config path` prints the
file; `microterm config edit` creates it from the commented template).

1. **Live colours.** Save `theme = "Dracula"` in the config: the whole window recolours within
   a fraction of a second. Try `"Catppuccin Mocha"`, then `theme = { dark = "Tokyo Night", light =
   "Tokyo Night Day" }` and switch the OS between light and dark.
2. **Live layout.** Add `[window]` with `padding = { x = 24, y = 16 }`: the grid reflows and
   `stty size` matches the new viewport. Add `[font]` with `size = 16` and watch the cell size
   change.
3. **Live keybindings.** Add
   ```toml
   [[keys]]
   key = "ctrl+alt+k"
   action = "ShowCommandPalette"
   ```
   `Ctrl+Alt+K` opens the palette, whose key chip now shows it. Bind `cmd+t` (macOS) or
   `ctrl+shift+t` (Linux) to `"Disable"` and the shortcut stops working.
4. **Error banner.** Break the file (`size = = 1` or `[font`). A red banner shows
   `microterm.toml:LINE:COL — …Using the last valid config.` and the app keeps the previous look.
   Fix the file and the banner disappears.
5. **Unknown key.** Add `fnt = 1`: an amber banner suggests `did you mean "font"?` and the rest of
   the file still applies. **Open config** opens the file in `$EDITOR` in a new tab.
6. **Theme selector.** `Cmd/Ctrl+Shift+P` → "Select theme": all 53 themes are listed; moving
   the selection previews live, `Esc` reverts, `Enter` keeps it.
7. **Terminal behaviour.** `[cursor] style = "beam"`, `[scrollbar] mode = "always"`,
   `[bell] mode = "none"`, `[window] opacity = 0.9` and `[tab_bar] hide_if_single = true` all
   take effect on save. `scrollback_lines`, `shell` and `env` apply to new panes only.
8. **Reload action.** `Cmd/Ctrl+Shift+R` reloads and toasts what changed.
9. **CLI.**
   ```sh
   microterm config path
   microterm config check            # exit 1 with file:line:col on errors
   microterm config show-defaults
   microterm themes list --json
   microterm themes show "Nord"
   ```
10. **User themes.** Copy a file from `themes/` into `~/.config/microterm/themes/`, change its
    `name` and colours, and it appears in the selector immediately.
11. **Validation.** `make themes` checks every bundled theme (licence, 16 colours, ≥ 4.5:1
    contrast).
