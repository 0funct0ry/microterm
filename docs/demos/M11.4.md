# M11.4 — Main application menu demo

```sh
make run
```

1. **Bar.** The menu bar shows microterm, Shell, Edit, View, Window and Help. Shell ▸ New Tab shows `⌘T`.
2. **Greying.** With one pane, Shell ▸ Close Pane and Window ▸ Rotate Panes are grey. Choose Shell ▸ Split Right: they enable. Copy (Edit) is grey until you select text.
3. **Link.** `echo https://example.com`, hover the link, then Shell ▸ Open Link at Mouse Cursor opens it.
4. **Domains.** Add to `microterm.toml`:
   ```toml
   [[ssh_domains]]
   name = "github.com"
   host = "github.com"
   ```
   Shell ▸ New Tab in Domain lists *Local* and *SSH: github.com*; choosing it opens a tab there.
5. **Rebind.** Add `[[keys]] key = "cmd+alt+d" action = "SplitHorizontal"`; after the reload Shell ▸ Split Right shows `⌘⌥D`.
6. **Reset.** `printf '\e[?2004h'`, then Shell ▸ Reset Terminal: bracketed paste is off, scrollback is intact.
7. **Detach / Attach.** Create a second workspace (`⌘⌥W`). Shell ▸ Detach Workspace switches away; Shell ▸ Attach ▸ name returns with the shells still running. Detach is grey with one workspace; Attach is grey when nothing is detached.
8. **ctl.**
   ```sh
   microterm ctl menu-bar list
   microterm ctl menu-bar list --json | jq '.items[] | select(.enabled | not)'
   ```
9. **Off.** Set `[menu_bar] enabled = false`: only the microterm menu (with Quit) remains.
