# M11.2 — Shell-registered menu items demo

```sh
make run
```

1. **Load the integration.** In the shell of a pane:
   ```sh
   eval "$(microterm shell-integration zsh)"      # or bash / fish
   ```
2. **Register an item.** Run `mt-menu add "Run tests" -- echo tests-ran`. Right-click the pane:
   after your config rows a **Shell** heading shows "Run tests" with a `shell` chip. Click it:
   `echo tests-ran` is typed into that pane and runs.
3. **Headless.** `microterm ctl menu show viewport --pane $MICROTERM_PANE --json` lists the row
   with `"origin": "shell"`; `microterm ctl menu invoke viewport/shell:run-tests --pane
   $MICROTERM_PANE --dry-run` prints the text that would be typed.
4. **Lifecycle.** `mt-menu clear run-tests` removes it; add it again, then run `clear` (or `exit`
   the shell): the item is gone.
5. **Hostile output.** `printf '\033]7717;menu;add;x;RXZpbA==;spawn;WyJzaCJd\007'` registers a
   `spawn` item: it is shown disabled and `ctl menu invoke viewport/shell:x --pane …` fails with
   "directory not trusted". Add the current directory to `[menu_security] trusted_dirs` in
   `microterm.toml` (it reloads live): the row is enabled and opens a split.
6. **Project menu.** In a trusted directory create `.mt-menu.toml` (aliases `.microterm-menu.toml`, `.menu.toml` and `.p-menu.toml` work too):
   ```toml
   [[items]]
   label = "Say hi"
   send = "echo hi"
   ```
   Right-click: a **Project** heading offers "Say hi". Remove the directory from `trusted_dirs`:
   the menu shows ".mt-menu.toml ignored: directory not trusted".
7. **ssh.** Over an ssh domain, `mt-menu add` items are ignored unless
   `[menu_security] allow_remote_items = true`; with it they show under **Shell (remote)** and ask
   for confirmation, and survive a reconnect.
