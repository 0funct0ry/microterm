# M10.5 — `microterm sh` demo

```sh
make run
```

Run `microterm sh` in a **second terminal** (outside microterm), or in a tab of the running window.

1. **Start and explore.**
   ```sh
   microterm sh
   ```
   The prompt is `microterm> `. Type `list`: a box-drawn tree of workspaces, windows, tabs and
   panes (`●` focused, `▸` active). Type `pane list`: a coloured table with a `N panes` footer;
   shrink the terminal and the `DOMAIN` column goes first.
2. **Complete IDs and selectors.** Type `pane get --pane ` and press Tab: every pane ID is listed
   with its title and directory. Type `pane list --match ` and Tab for the selector keys, then
   `status:` Tab for `idle working waiting done error`. While you type `title:b*` the hint after the
   cursor reads `matches 1 pane`; `bogus:1` points at the column of the mistake.
3. **Use a context.**
   ```text
   microterm> use pane 7            # an ID from step 2
   microterm[pane 7]> pane get      # same as: pane get --pane 7
   microterm[pane 7]> cat           # alias for pane get-text
   microterm[pane 7]> type 7 'echo hi'   # send-text always names its target; never the context
   microterm[pane 7]> use -
   ```
4. **Create and wait with variables.**
   ```text
   microterm> tab new --title build -- sh -c 'sleep 2; echo ready'
   ✔ tab 9 created (pane 12, window 1)
   microterm> pane wait $pane --match ready --timeout 30s ; echo done
   ```
   `$tab`, `$pane` and `$window` hold the IDs of the last `new`.
5. **Close with the confirmation prompt.** Set `confirm_close = "always"` in your config, then:
   ```text
   microterm> tab close 9
   confirm_close would ask before closing tab 9. Close anyway? [y/N] y
   ```
   `microterm sh -c 'tab close 9'` never prompts: it exits `8` and closes nothing.
6. **History and search.** Press Ctrl-R and type `pane`: earlier commands come back. `type 7 hi`
   lines are not saved (`[sh] history_send_text = true` keeps them). Ctrl-D leaves.
7. **Scripts and parity.**
   ```sh
   microterm sh -c 'pane list' --json | diff - <(microterm ctl pane list --json) && echo identical
   microterm sh --readonly -c 'pane close 9'; echo $?    # 1: rejected before it reaches microterm
   printf 'list\npane list\n' | microterm sh
   ```
