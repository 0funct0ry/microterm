# M12.1 — Recording engine and store demo

Recording is off by default, so the first step shows it inert.

```sh
make run
```

1. **Off by default.** In a pane of the running app: `microterm ctl recording list; echo $?`
   prints a "recording is disabled" message and `10`, and
   `ls ~/.local/share/microterm/recordings` says the directory does not exist.
2. **Turn it on.** Add `[recording]` / `enabled = true` to `microterm.toml` (it applies at once).
   `microterm ctl recording list` now prints nothing and exits `0`; the directory is still not
   created.
3. **Record.** `microterm ctl recording start --pane $MICROTERM_PANE` prints an id like
   `r_20261022_141503_ab12cd`. Type a few commands, run `microterm ctl recording marker --pane
   $MICROTERM_PANE --label "checkpoint"`, then `microterm ctl recording stop --pane
   $MICROTERM_PANE`.
4. **Inspect.** `ls -l ~/.local/share/microterm/recordings` shows `r_*.cast` and `r_*.json`
   (`-rw-------`; the directory is `drwx------`). `microterm ctl recording list` and `show ID`
   print the title, duration, size and the marker count.
5. **Replay.** `microterm ctl recording replay ID --speed 4` plays it into a new tab. The same
   file plays outside microterm: `asciinema play ~/.local/share/microterm/recordings/ID.cast`.
6. **Rename and delete.** `ctl recording rename ID "my demo"`. `ctl recording rm ID` exits `8`
   and keeps the files; `ctl recording rm ID --force` removes both.
7. **Crash safety.** Start a recording, wait two seconds, then `kill -9` the microterm process
   and start it again. `ls` shows an `r_*.cast.partial` until `microterm ctl recording list`
   runs; the list then shows the recording with the flag `recovered` and the partial is gone.
8. **Input and passwords.** `ctl recording start --pane $MICROTERM_PANE --input`, type a command,
   then run `sudo -k; sudo true` and type a password. After `stop`, the `.cast` has `"i"`
   events for the command but none for the password: one `"m"` event reads
   `input paused (no echo)`.
9. **Limits.** Set `max_duration_minutes = 1` (or `max_size_mb = 1`) and start a recording on a
   noisy command; it stops and is saved on its own.
10. **Turning it off.** With a recording running, set `enabled = false`: the recording is stopped
    and saved, and `ctl recording list` exits `10` again.
