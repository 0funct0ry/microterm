# M11.01 — Workspace designer demo

```sh
make run
```

1. **Open.** Command palette (`⌘⇧P`) → "Design Workspace…". A 720 px modal opens.
2. **Build `shop`.** Click New, click the name field and type `shop`, press Enter. Click the star
   to make it the startup workspace.
3. **Split.** Click "Split right", then with the new pane selected "Split down". The canvas shows
   three panes; the depth counter reads 2/4. Click a pane and fill `cwd` / `command`
   (`cargo watch -x run`). Arrow keys nudge the divider by 5.
4. **Preview.** Click "TOML preview": only `[[workspaces]]` lines and `startup_workspace` change.
5. **Save.** Click "Save to config". `microterm.toml` now has the nested form, everything else is
   byte-identical, `microterm.toml.bak` holds the old file, and `shop` is in the switcher.
6. **Invalid layout.** Rename a workspace to an existing name: an error with its TOML path
   appears and Save is disabled.
7. **Stale file.** Open the designer, edit `microterm.toml` in an editor, then Save: it refuses.
8. **Esc.** With unsaved edits, Esc asks; Esc again discards and focus returns to the terminal.
9. **Save current layout.** Split a tab with `⌘D`, run "Save current layout as workspace…".
