# M11 — Splits and focus follows mouse demo

```sh
make run
```

1. **Split.** Press `⌘D` (Linux `Ctrl+Shift+D`): a second shell appears to the right and takes
   focus. Press `⌘⇧D` (`Ctrl+Shift+E`): the right pane splits into top and bottom. The unfocused
   panes are dimmed; the focused one has a thin accent border. Type in each pane.
2. **Move focus.** `⌘⌥←` / `→` / `↑` / `↓` (`Ctrl+Alt+arrows`) move to the neighbouring pane and
   stop at the edges. Click a pane to focus it (the click is not sent to the program).
3. **Resize.** Drag a divider; the pointer becomes a resize cursor over the 6 px grab area. Watch
   `ls` or `htop` reflow in the pane you resized. From the palette: "Resize pane left".
4. **Zoom, swap, rotate.** Palette (`⌘⇧P`): "Toggle pane zoom" shows one pane full-size without
   dividers; run it again, or move focus, to restore. "Swap pane left" and "Rotate panes" reorder.
5. **Close.** Palette: "Close pane". Closing the last pane of the tab closes the tab. A pane
   running a program asks first under `confirm_close = "process"`.
6. **Focus follows mouse.** Add to `~/.config/microterm/microterm.toml` (it reloads live):
   ```toml
   [mouse]
   focus_follows_mouse = true
   [panes]
   focus_delay_ms = 150
   ```
   Hover another pane: it takes focus after 150 ms. Sweep across a pane quickly and focus stays.
7. **Declared splits.** Add
   ```toml
   [[workspaces]]
   name = "demo"
   tabs = [
     { title = "dev", split = "horizontal", percent = 60, panes = [
         { command = ["sh"] },
         { split = "vertical", panes = [ { command = ["top"] }, { command = ["sh"] } ] },
     ] },
   ]
   ```
   then switch to `demo` from the workspace chip: the tab opens with three panes.
8. **Script it.** From a pane:
   ```sh
   microterm ctl pane split --vertical --percent 30 -- htop
   microterm ctl list                       # tab 5 "dev"  [1 | (2 / 3)]
   microterm ctl pane focus --direction left
   microterm ctl pane zoom
   microterm ctl pane resize --direction right --cells 10
   microterm ctl list --json | jq '.workspaces[].windows[].tabs[].layout'
   ```
9. **SSH.** Open a tab on an SSH domain (launcher), split it, and run `top` in one pane and
   `htop` in another. Cut the connection (`ifconfig en0 down`, or kill the `ssh` process):
   the reconnect card appears. Restore it: all panes re-attach, the layout is unchanged and the
   programs keep running.
