# M12.75 — Collapsible output and semantic links demo

```sh
make run
```

Set `[private_osc]` / `enabled = true` in `microterm.toml` first. The steps are scripted in
`scripts/private_osc/fold` and `scripts/private_osc/link` (also run by `all`).

1. **Fold.** Run `mt-fold begin build "Build"; seq 1 40; mt-fold end build`. Run **Fold all output
   regions** from the palette: the 40 lines become one `▸ Build · 40 lines` row. Click it: expanded again.
2. **Copy.** Collapse the region, drag a selection across the summary row and copy: the clipboard holds
   the hidden lines too.
3. **Search.** Collapse it, open Search and look for `27`: the region expands at the hit.
4. **Resize.** Resize the window: the folds stay.
5. **fold_commands.** Set `fold_commands = true` with shell integration, run a command with output
   and Fold all: its output folds under the command name.
6. **Link rule.** `mt-link add issue '#(\d+)' 'https://example.com/issues/$1'; echo "see #4821"`. Hold the
   link modifier over `#4821`: the tooltip shows `https://example.com/issues/4821`.
7. **Ranking and schemes.** An OSC 8 link or your own rule on the same text wins. A rule whose template
   uses `ssh://` is blocked ("Blocked link scheme").
8. **SSH.** In an SSH pane folds work; link rules are ignored until `[menu_security] allow_remote_items = true`.
9. **Master switch / gates.** Toggle private OSC (or set `fold = false` / `link = false`): folds and rules
   vanish and the actions only show a toast. `ED 3` or `reset` clear folds.
