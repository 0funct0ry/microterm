# M12.72 — Progress bars and declared tab color demo

```sh
make run
```

Set `[private_osc]` / `enabled = true` in `microterm.toml` first. The steps are scripted in
`scripts/private_osc/` (`progress` and `tab_color`, also run by `all`).

1. **Three stages.** Run `scripts/private_osc/progress`: the tab gets a progress line on its
   bottom edge (the mean of the determinate stages), a strip above the status bar lists the three
   bars (the third pulses), and hovering the tab lists `Fetch 25 % · 38 s left`, `Build …` and so
   on. No notification fires and the tab gets no attention marker.
2. **Done.** The script finishes each bar with `done`: it reads 100 % for 2 seconds, then is gone.
3. **Live status wins.** While bars run, `microterm ctl pane status set --state working --progress 70 tests`
   takes over the line; the bars stay listed in the tooltip.
4. **Declared color.** `printf '\e]7719;tab;color;orange\a'` tints the tab; the tooltip says
   `Color: orange (declared by pane N)`.
5. **Precedence.** Right-click the tab and pick *pink*: pink wins. Pick *Default*: orange is back.
   `microterm ctl tab color red` style trigger colors also win over it.
6. **Clear.** `printf '\e]7719;tab;color;\a'`, closing the pane, or `reset` removes the color.
7. **Master switch.** Toggle private OSC from the palette: bars and color vanish and do not come
   back when it is turned on again. The same happens with `[private_osc.features] progress = false`
   or `tab = false` for just that feature.
8. **Over SSH.** In an SSH pane run steps 1 and 4, drop and restore the connection: both are
   restored by the daemon replay.
