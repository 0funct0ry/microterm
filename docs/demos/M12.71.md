# M12.71 — Private OSC demo

```sh
make run
```

The steps below are scripted in `scripts/private_osc/` (run inside a microterm pane after enabling
`[private_osc]`): `caps` (step 3), `status` (steps 2 and 4), `master_switch` (steps 5 and 6) and
`all` for every one in turn.

1. **Off by default.** In a pane run:
   `printf '\e]7725;status;set;git;%s;ok\a' "$(printf main | base64)"`. Nothing prints, no chip
   appears and there is no status bar. `microterm ctl private-osc status` shows `enabled off` and
   `swallowed_off 1` for the pane. `printf '\e]7727;caps;query\a'` gets no reply.
2. **Turn it on.** Put `[private_osc]` / `enabled = true` in `microterm.toml` and save (hot
   reload). Repeat the `7725` command: a green `main` chip appears at the bottom right; hover it
   ("Set by a program in pane N"). Switch to another tab: the chip is gone; back: it returns.
3. **Handshake.** `printf '\e]7727;caps;query\a' | cat` is not enough (the reply goes to the
   pane's input); use the `stty`/`dd` snippet from the *Private OSC* docs page. The JSON lists
   `status` and `caps` as `1`, the not-yet-built features as `0`, and nothing else.
4. **Clear.** `printf '\e]7725;status;clear;git\a'` removes the chip.
5. **Master switch off.** Set a chip again, then run **Toggle private OSC** from the palette: the
   chip disappears, a lock icon shows at the bottom left, and a new `7725` sequence prints nothing
   and changes nothing (`cat` of a file full of `ESC ] 77xx` bytes prints nothing either). Run the
   action again: the old chip does **not** come back. A shell-registered `mt-menu` item is gone
   too.
6. **No way back from outside.** `microterm ctl private-osc disable` works;
   `microterm ctl private-osc enable` is a usage error, and no sequence a program prints turns the
   switch on.
7. **Over SSH.** In an SSH pane set a chip, then drop and restore the connection: the chip is
   restored by the daemon replay.
8. **Events.** `microterm ctl events --type private_osc.changed` prints a line per change, with the
   feature name and no content.
