# M7 — Mouse, selection and hyperlinks demo

```sh
make run
```

1. **Select.** Run `echo alpha-beta /usr/local/bin gamma`. Drag across some text, then
   double-click `/usr/local/bin` (the whole path selects), triple-click the line, and
   Alt/Option-drag a rectangle. `Cmd/Ctrl+C` (Linux: `Ctrl+Shift+C`) copies; paste with
   `Cmd/Ctrl+V`. Shift+click extends the selection. Typing clears it.
2. **Auto-scroll.** Run `seq 1 500`, then drag from the bottom and keep the pointer above the
   top edge: the view scrolls and the selection grows.
3. **Right-click.** Right-click: Copy, Paste, Select all, Open link, Copy link, Search for
   selection, Clear scrollback. Set `mouse.right_click = "paste"` and save: it pastes instead.
4. **Mouse mode.** Run `vim`, then `:set mouse=a`. Clicking moves the cursor and dragging
   makes a visual selection. Hold **Shift** and drag: microterm selects instead. Run `htop`: the
   rows respond to clicks and the wheel.
5. **Alternate scroll.** Run `man ls` or `less /etc/hosts`: the wheel scrolls the pager.
6. **OSC 8 links.** `ls --hyperlink=auto` (GNU ls) or
   `printf '\e]8;;https://example.com\e\\click me\e]8;;\e\\\n'`. Hover: the text gets a dotted
   accent underline and a tooltip with the real target. **Cmd/Ctrl-click** opens it.
7. **Implicit links.** `echo https://github.com/0funct0ry/microterm localhost:3000` — both are
   links. Right-click one for *Copy link*.
8. **Custom rule.** Add to the config and save (hot reload):

   ```toml
   [[hyperlink_rules]]
   regex  = '\b([A-Z]{2,}-\d+)\b'
   format = "https://example.atlassian.net/browse/$1"
   ```

   `echo fix PAY-12` now makes `PAY-12` a link.
9. **Allowlist.** `printf '\e]8;;ftp://example.com\e\\ftp\e]8;;\e\\\n'` and Cmd/Ctrl-click: a
   toast says the scheme is blocked until you add `"ftp"` to `hyperlinks.schemes`.
10. **Linux.** Selecting sets the primary selection; middle-click pastes it.
