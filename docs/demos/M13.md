# M13 — Release engineering and website demo

Prerequisites: `make setup` (installs cargo-about, site dependencies), `rsvg-convert` and
ImageMagick (`brew install librsvg imagemagick`) for `make icons`.

1. **Icon.** `make icons`, then open `packaging/icon/generated/microterm-1024.png`: a μ inside a
   terminal window on a dark tile. `packaging/icon/generated/hicolor/` has 16–512 px and the SVG.
2. **Licences.** `make licenses && make licenses-check`. `THIRD-PARTY-LICENSES.html` lists the crates,
   the fonts, the icons and every theme. Edit `assets/LICENSES.md` (drop the Lucide row) and
   `make licenses-check` fails.
3. **Bundle.** `make bundle` (macOS), then:
   ```sh
   plutil -lint dist/stage-*/microterm.app/Contents/Info.plist
   codesign --verify --strict dist/stage-*/microterm.app
   file dist/stage-*/microterm.app/Contents/MacOS/microterm-app dist/stage-*/microterm.app/Contents/Resources/bin/microterm
   ls dist/stage-*/microterm.app/Contents/Resources     # LICENSE, THIRD-PARTY-LICENSES.html, microterm.icns, bin/
   ```
   The `.dmg` mounts with the app, `LICENSE` and `THIRD-PARTY-LICENSES.html`.
4. **Launcher.** From a terminal run `dist/stage-*/microterm.app/Contents/Resources/bin/microterm`
   (or symlink it onto `PATH`). The app starts and the **Dock shows the μ icon**. Run it again: a new
   window opens in the same instance. `microterm --help`, `microterm --version --verbose` and
   `microterm ctl pane list` behave exactly like the app binary (`cargo test -p mt_launcher`).
5. **About.** Menu → **About microterm**: dialog with the logo, version, licence and a
   **Third-party notices** button that opens the bundled file. Esc closes it.
6. **Dev Dock icon.** `make run`: the Dock shows the μ icon, not the generic exec icon.
7. **Release dry run.** `make release-dry` builds this machine's artefacts, the static
   `microterm-mux`, writes `dist/SHA256SUMS` and fails if any artefact lacks the licence files.
8. **Install script.**
   ```sh
   MICROTERM_RELEASE_BASE=file://$PWD/dist sh scripts/install.sh --version v1.0.0 --prefix /tmp/mt-prefix --no-modify-path
   /tmp/mt-prefix/bin/microterm --version --verbose      # License: MIT
   ```
   A corrupted archive fails with `checksum mismatch`.
9. **Website.** `make site-dev`: the marketing page at `/microterm/` (try Quick select, Copy mode, the
   palette and the SSH drop in the demo; toggle light/dark) and the docs at `/microterm/docs/…`
   with search, the new Upgrading, Key bindings, Roadmap, Changelog, Contributing, Licences and
   Configuration reference pages. `make site-build` also writes `install.sh` and the licence notices.
10. **Release (maintainer).** Follow `docs/release-checklist.md`: set secrets, tag `v1.0.0`, check the
    draft release, publish, check the tap and the site.
