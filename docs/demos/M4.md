# M4 — Typography demo

```sh
make run
```

1. **Ligatures.** In the first tab run `printf '==> != <= >= -> => <-> ::\n'`. In JetBrains
   Mono the operators join. Move the cursor over one (`printf '==> '` and press Left) and that
   ligature breaks into single cells while the others stay joined; it returns when the cursor
   leaves.
2. **No ligatures.** Add `[font]` with `ligatures = false` to the config: all operators split
   within a fraction of a second. Set it back to `true`.
3. **Emoji and CJK.** `echo '🦀 漢字 日本語'`: the crab and each character fill two cells, aligned
   with the columns above and below (`printf 'abcdefgh\n🦀漢字ab\n'`). `echo 🇯🇵🇫🇷` draws flags.
4. **Powerline and Nerd glyphs.** `printf '\ue0b0 \uf015 \ue7a8\n'` renders arrows and icons without
   gaps, with no Nerd Font installed.
5. **Fallback chain.** `microterm ls-fonts --text "λ→🦀漢"` prints the chain and, per character,
   the font used and why. Add `fallback = ["Noto Sans CJK JP"]` and run it again.
6. **Font size.** `Cmd/Ctrl +` / `-` / `0` resize the text in this window only. Run `stty size`
   after each: the grid and the PTY follow, and the resize HUD shows briefly.
7. **Live reload.** Change `[font] family` or `size` in the config while two windows are open:
   both re-layout. Setting `size` replaces any `Cmd/Ctrl +` zoom.
8. **Features.** `features = ["zero"]` shows a slashed zero in JetBrains Mono (`echo 0000`).
