# M12.3 — Exporters (cast and VHS) demo

Needs `recording.enabled = true` (and `capture_input = true` for the VHS steps).

```sh
make run
```

1. **Record.** `⌘⌥R`, type `echo hello` + Enter and a few other commands, `⌘⌥R` again.
   `microterm ctl recording list` shows the id.
2. **Formats.** `microterm ctl recording export --list-formats` lists `cast` and `vhs` with their
   options, defaults and ranges.
3. **VHS.** `microterm ctl recording export ID --format vhs -o demo.tape` and read `demo.tape`
   (`Type@…ms "echo hello"`, `Enter`, `Sleep …`). If VHS is installed, `vhs demo.tape` replays the
   typed commands.
4. **Shortened cast.** `microterm ctl recording export ID --format cast --opt idle_limit=1 --opt
   strip_input=true -o short.cast`, then `microterm ctl replay short.cast`: the pauses are at most
   one second and no keystroke events remain.
5. **No overwrite.** Repeat step 4: it fails; add `-f` and it succeeds.
6. **Exit 12.** Record a pane without input and run the VHS export: exit `12` ("this recording has
   no input events"). `--opt bogus=1` also exits `12`.
