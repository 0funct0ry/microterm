# M2 — Live terminal demo

The first tab now runs your shell. Use `Cmd` on macOS and `Ctrl+Shift` on Linux where noted.

```sh
make run
```

1. **Shell.** The `zsh`/`bash` tab shows your real prompt. `echo $TERM $COLORTERM $TERM_PROGRAM`
   prints `xterm-256color truecolor microterm`.
2. **Colours and styles.** Run `scripts/sgr-test.sh`: bold, dim, italic, reverse, strikethrough,
   five underline styles (including coloured curly), 16/256/truecolor ramps, box drawing,
   blocks, powerline and Braille glyphs all look right and line up on the grid. The script also
   cycles the cursor through block, beam and underline.
3. **`ls --color`.** `ls -G` (macOS) or `ls --color` shows coloured entries.
4. **Full-screen programs.** `vim`, `htop` and `less README.md` draw correctly, use the alternate
   screen, and leave your scrollback intact on exit.
5. **Typing.** Typing is instant. `Ctrl+C` interrupts `sleep 30`; arrow keys, history and
   `Alt+B`/`Alt+F` word motion work (on macOS `Option` is Alt).
6. **Scrollback.** `seq 1 500`, then scroll with the wheel or trackpad: a scrollbar appears while
   scrolling. `Shift+PageUp`/`PageDown`, `Shift+Home`/`End` move by page and to the ends; typing
   returns to the bottom. `Cmd/Ctrl+Shift+K` clears scrollback.
7. **Paste.** Copy `echo one` and press `Cmd/Ctrl+Shift+V`: it lands at the prompt. Copy two lines
   and paste: a confirmation card appears (Enter pastes, Esc cancels). Inside `vim` (bracketed
   paste on) the same paste inserts without a prompt.
8. **Titles.** `printf '\033]0;hello\007'` renames the tab and window title.
9. **Bell.** `printf '\a'` flashes the viewport briefly.
10. **Resize.** Drag the window edge: the `cols×rows` indicator appears and `stty size` (or `tput
    cols; tput lines`) matches it.
11. **Cursor.** The cursor blinks; click another app and it becomes a hollow block.
12. **Throughput.** `make bench` prints the parser and `cat` throughput and writes
    `bench/results/<date>.json`.

Other tabs (`cargo watch`, `ssh: prod`) are still mock data until M5.

Verification commands: `make lint && make test && make site-build`.
