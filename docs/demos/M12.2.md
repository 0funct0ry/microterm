# M12.2 — Recording mode demo

Recording is off by default, so the first step shows it inert.

```sh
make run
```

1. **Off by default.** Press `⌘⌥R` (`Ctrl+Alt+R` on Linux): only a toast "Recording is disabled —
   set `recording.enabled = true`" with an **Open config** button appears. No pill, no tab dot, no
   palette or Edit-menu row.
2. **Turn it on.** Add `[recording]` / `enabled = true` to `microterm.toml` (applies at once). The
   palette now has "Start Recording" and the Edit menu has **Start Recording**.
3. **Record.** `⌘⌥R` shows the toast "Recording started" and a `REC 00:01…` pill at the top right;
   the tab gains a red dot (hover it: `Recording pane N — 00:05`). Type commands; the shell works
   normally and `Esc` still reaches it.
4. **Stack.** Open copy mode (palette: "Copy mode") while recording: the `REC` pill stays to the
   left of `COPY`.
5. **Background tab.** Open a second tab: the first tab keeps its red dot.
6. **Stop.** `⌘⌥R` again: "Saved ‹title› · 00:42 · 1.2 MB" with **Open panel** / **Export…**
   (both inert until M12.4). `microterm ctl recording list` shows the file. Clicking the pill
   stops it too.
7. **Close saves.** Start a recording, then close the pane (`exit`): the recording is saved.
8. **Gate off.** Start a recording and set `enabled = false`: "Recording stopped: disabled in
   config", the file is saved, the pill and dot disappear.
