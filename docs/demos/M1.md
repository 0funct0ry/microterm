# M1 — UI shell demo

Everything here runs on mock data. Use `Cmd` on macOS and `Ctrl+Shift` on Linux where noted.

```sh
make run
```

On a Mac with only the Command Line Tools, the Makefile enables GPUI's runtime shader
compilation automatically, so no Xcode install is needed.

1. **Window anatomy.** A 34 px title bar (workspace chip `payments ▾` on the left, centred title,
   `● local` on the right; macOS shows traffic lights, Linux draws min/max/close), a 32 px tab bar
   with `zsh`, `cargo watch` (blue dirty dot) and `ssh: prod`, then the viewport with a fake
   prompt, `git log --oneline` output and a line showing bold / italic / underline / curly /
   strikethrough.
2. **Tabs.** Click a tab to switch content. `+` adds a tab. `×` (or middle-click) closes one.
   Right-click a tab for a context menu. Right-click `+` opens the launcher.
   `⌘T` / `Ctrl+Shift+T`, `⌘W` / `Ctrl+Shift+W`, `⌘1…9` / `Alt+1…9`, next / previous tab.
3. **Command palette** (`⌘⇧P` / `Ctrl+Shift+P`). Type `new` to filter, ↑ ↓ to move, Enter to run,
   Esc to close. Keybinding chips are rendered per platform.
4. **Launcher** (`⌘⇧L` / `Ctrl+Shift+L`). Profiles, SSH domains with status dots, workspaces.
5. **Workspace switcher** (`⌘⌥W` / `Ctrl+Alt+W`, or click the chip). Last row is
   "Create workspace…". `⌘⌥]` / `Ctrl+Alt+]` cycles workspaces.
6. **Theme selector** (palette → "Select theme"). Moving the selection recolours the whole UI;
   Esc reverts, Enter keeps it.
7. **Quick select** (`⌘⇧Space` / `Ctrl+Shift+Space`). Label chips appear over hashes and IPs
   (switch to the `ssh: prod` tab for IPs). Type a label to copy that text; the toast says
   "Copied …". Esc cancels.
8. **Copy mode** (`⌘⇧X` / `Ctrl+Shift+X`). The COPY pill appears and a block cursor starts on the
   last row. Move it with `h j k l` (also `0 $ g G`).
9. **Search** (`⌘F` / `Ctrl+Shift+F`). Type `main`: matches highlight, the bar shows `1 of N`,
   Enter / Shift+Enter step, the toggles switch case sensitivity (Alt+C) and regex (Alt+R).
10. **Toasts, config error banner, SSH overlay.** Palette → "Debug: Show toast", "Debug: Show
    config error banner", "Debug: Show SSH reconnect overlay" (attempt counter ticks every 2 s;
    the title bar goes amber; "Reconnect now" / "Close tab").
11. **Resize HUD.** Drag the window edge: a centred `120×40`-style pill shows and fades 600 ms
    after the last resize.
12. **Focus.** After every overlay closes, typing/shortcuts go back to the viewport.

Verification commands:

```sh
make lint && make test && make site-build
```
