# M9 — CLI, IPC and recording demo

```sh
make run
```

Run the following in a **second terminal** (or a shell inside microterm: the variables below are
already set there).

1. **List.** `microterm cli list` prints the workspaces, windows, tabs and panes. With
   `--json` you get the same as JSON. With the app closed it exits with code 2:
   `microterm cli list; echo $?`.
2. **Workspace and tabs.**
   ```sh
   microterm cli workspace create demo
   a=$(microterm cli spawn --workspace demo --title build -- sh -c 'echo building; sleep 600')
   b=$(microterm cli spawn --title logs -- sh -c 'while :; do date; sleep 1; done')
   c=$(microterm cli spawn --title shell)
   ```
   The window switches to the `demo` workspace and shows three tabs. Each command printed its
   pane id.
3. **Read output.** `microterm cli get-text --pane $a` prints `building`. `get-text --pane $b
   --start-line -5` shows the last lines; `--escapes` keeps colours.
4. **Type into a tab.** `microterm cli send-text --pane $c 'echo hi from the cli'` pastes the
   text; add a trailing newline (`$'...\n'`) to run it. `--no-paste` sends raw bytes.
5. **Tabs.** `microterm cli activate-tab --tab-index 0`, `set-tab-title --tab-id ID renamed`,
   `kill-pane --pane $c`.
6. **Record and replay.**
   ```sh
   microterm cli record --pane $b -o /tmp/logs.cast --duration 5
   microterm cli replay /tmp/logs.cast --speed 2
   ```
   A new tab replays the clock output at double speed. `asciinema play /tmp/logs.cast` plays the
   same file.
7. **Record a command.** `microterm record -o /tmp/ls.cast -- ls -la` opens a tab, records,
   and returns when `ls` finishes.
8. **Watch events.**
   `printf '{"v":1,"id":1,"method":"subscribe"}\n' | socat - UNIX-CONNECT:$MICROTERM_UNIX_SOCKET`
   then open a tab in the app: a `pane_added` line appears.
9. **Completions.** `microterm completions zsh | head`.
10. **Headless (tests).** `microterm --headless` prints a socket path and serves the same
    protocol without windows; `cargo test -p microterm --test ipc_e2e` drives it.
