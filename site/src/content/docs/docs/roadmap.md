---
title: Roadmap
description: What ships in each microterm release.
---

Each release is small and ships when it works end to end.

| Release | Theme | What it brings |
|---|---|---|
| **v1.0** (today) | Core terminal | Tabs, splits, workspaces, SSH domains with reconnect, serial ports, quick select, copy mode, the `ctl` command line, recording, themes, hot-reloaded TOML config |
| v1.2 | Pixels | Kitty and iTerm2 inline graphics |
| v1.3 | Lua config | Logic, variables and callbacks on the same schema as the TOML file |
| v1.4 | Plugins | One-line GitHub plugins, pinned to a commit |

Dates are not promised. The [Changelog](/docs/changelog/) records what has shipped and
[GitHub issues](https://github.com/0funct0ry/microterm/issues) is the place to ask for something.
